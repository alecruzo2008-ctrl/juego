# Huella Extinta

Videojuego educativo 2D de exploración sobre fauna colombiana, desarrollado con Godot 4 y GDScript.

## Abrir y ejecutar

1. Descarga Godot 4.3 o superior desde [godotengine.org/download](https://godotengine.org/download/).
2. Abre Godot, importa la carpeta del proyecto y ejecútalo con F6/F5.
3. Para validar desde una terminal, ejecuta `godot --headless --path . --quit`.

El código utiliza GDScript y el renderizador Compatibility. Los recursos provisionales se generan dentro del proyecto.
